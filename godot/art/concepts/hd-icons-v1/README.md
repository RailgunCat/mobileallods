# HD-концепты иконок · v1

Дата: 27 октября 2026. **Только концепты. К игре не подключены.**

Пакет создан встроенным image_gen по исходной Java ME графике. Это предложение художественного направления для будущей HD-версии, а не утверждённая замена. Оригинальные игровые текстуры, сцены, шрифты и код не изменялись.

Общий стиль: рисованное фэнтези с тёмным камнем, состаренной бронзой, холодной сталью и сдержанными зелёными акцентами; свет сверху слева. Это детальная растровая иллюстрация, а не новая пиксельная графика.

## Навигация по исходным ID

Порядок — слева направо, затем сверху вниз. [manifest.json](manifest.json) содержит строку/столбец, исходные image ID, item ID, spell ID и соответствия типов юнитов. Это карта смыслов; координаты точной нарезки пока не утверждены.

- Диалоговые портреты: изображения 16–24, сетка 3×3. Имена персонажей не угадывались по внешности; диалоговые и боевые назначения в исходном JAR местами различаются.
- Боевые портреты: изображения 205–219, сетка 5×3; соответствия взяты из unit_portrait_images.
- Магия: атлас 189, кадры 0–14; последняя ячейка — исходное оглушение, кадр 15.
- Броня: предметы 0–11, изображения 220–231.
- Оружие и фокусы: предметы 12–35, изображения 232–255. Нижний ряд — предметы 36–40, кадры 0–4 атласа 257, затем пустое гнездо.

## Что проверено и что предстоит

Проверены фактические размеры, PNG CRC и распаковка всех шести файлов; листы просмотрены визуально. Изображения имеют непрозрачные презентационные фоны. Генератор выдал размеры, перечисленные выше: пожелание 2K в промптах не является гарантией выходного размера. Геометрия ячеек приблизительная; эти листы нельзя подключать как готовые атласы.

Перед внедрением: согласовать стиль; отдельно уточнить внешность и общую идентичность персонажей по диалогам/боевым портретам; нарезать или перерисовать отдельные PNG с альфа-каналом; упростить детали для 24/32/48/64 px; подготовить состояния normal/hover/pressed/disabled и реальные границы/отступы; проверить на тёмных и светлых фонах внутри Godot. Цвета отметок карты, формы курсоров и декоративные детали здесь являются вариантами концепта, не новыми игровыми правилами. Для production-мастеров можно заново сгенерировать каждый выбранный значок отдельно в высоком разрешении.
