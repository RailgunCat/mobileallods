# HD-интерьеры таверны и магазина · v1

28 октября 2026. Рабочий прототип в Godot, включается в настройках HD-режима.

Использованы ранее сгенерированные встроенным image_gen фоны:

Это непрозрачные интерьеры без вшитого интерфейса. Тексты, кнопки, товары,
цены и сравнение рисуются в Godot из текущего игрового состояния. Картины
показываются с сохранением пропорций и заполнением фона. Шрифт, каменные
рамки и состояния кнопок взяты из LegacyTheme проекта по просьбе пользователя.

Промпты и входные референсы сохранены в prompts.json; происхождение и SHA-256 —
в manifest.json. Новых генераций в этом этапе не было. Копии исходников идентичны
концептам, оригинальная Java ME графика не перезаписана.

Проверка: Godot 4.7, tests/hd_town_checks.gd. Превью: build/hd-town-tavern.png,
build/hd-town-shop.png, build/hd-town-stock.png, build/hd-town-work.png и другие.
Сгенерированные фоны, промпты и метаданные входят в Git. Исходные игровые
изображения и скачанные референсы остаются локальными.
